# Petty cash PRD — implemented and superseded

The analysis and change proposals previously kept in this file have been implemented in the current petty-cash V2 workflow. They were removed to prevent the proposed design and the implemented process from being mistaken for two different operating procedures.

Use [`docs/petty-cash-guide.md`](../docs/petty-cash-guide.md) as the single authoritative source for:

- the current fund-level replenishment and return process;
- IOU batch approval, independent release, bills, returned cash, and settlement;
- posting Expense accounts, job/cost-centre classification, and job spending limits;
- per-line receipt evidence, missing-receipt approval, and exact shortage vouchers;
- scheduled cash counts, reminders, permissions, legacy-data treatment, and worked examples.

Implementation completion date: **2026-08-24**.
